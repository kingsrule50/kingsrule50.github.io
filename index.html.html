My approach

Build the control. Check the outcome.

My labs follow a straightforward process, from a defined security objective to evidence that others can review.

Design with a clear scope

Define the resources, users and security requirements, then implement controls within the intended lab environment.

Validate the behavior

Use test cases, logs and read-only verification scripts to check access, policy enforcement and detection results.

Make the evidence useful

Record the configuration, results and limitations in GitHub so the work is easy to understand and review.

Build with purpose. Validate with evidence. Deploy with confidence.
